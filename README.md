# Text Analysis using Data Structures (Flask)

## Description
This is a Flask-based web application that performs text analysis using
Data Structures concepts such as arrays, sorting, and searching.

## Features
- Text preprocessing
- Word frequency analysis
- Top-K frequent words
- Keyword search
- File upload (.txt)
- Bar chart visualization
- Flask backend

## Technologies Used
- Python (Flask)
- HTML
- CSS
- JavaScript
- Chart.js

## How to Run
1. Install Flask: `pip install flask`
2. Run: `python app.py`
3. Open browser: `http://127.0.0.1:5000`
